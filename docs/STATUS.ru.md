# Статус — кандидат Node Beta 1

Эта страница — авторитетное заявление о статусе снимка форка. Канонический
язык — английский; переводы: [STATUS.md](STATUS.md) (EN) и
[STATUS.de.md](STATUS.de.md) (DE).

Словарь статусов, используемый во всей документации:

| Метка | Значение |
|---|---|
| **PASS** | Наблюдалось на указанном коммите и бинарнике, в указанной среде и сценарии; доказательство зафиксировано. |
| **PARTIAL** | Реализовано и частично проверено; хотя бы один обязательный сценарий, среда или потребитель не проверены. |
| **FAIL** | Наблюдаемый отказ в определённом сценарии. Не используется, если тест просто пропущен. |
| **NOT VERIFIED** | Подходящих доказательств нет. Пропущенный тест, отсутствующая фикстура, таймаут или mock — не PASS. |
| **PLANNED** | Только проект/план; доказательств принятой реализации нет. |
| **EXPERIMENTAL** | Код есть, включение только opt-in; не рекомендуется для production или обычной работы. |

## Критерии приёмки Node Beta 1

Критерии взяты из досье Node Beta. Они повторены здесь, чтобы «кандидат Beta 1»
не путали с «принятой Beta 1».

| # | Критерий | Статус | Основание / остаток |
|---|---|---|---|
| 1 | Полная синхронизация Mainnet с нуля до актуальной высоты и дальнейшее принятие блоков на одном финальном SHA, без искусственного короткого списка пиров | **NOT VERIFIED** | Mainnet на кандидате не запускался. Floonet — не Mainnet. |
| 2 | Полный PIBD на одном финальном SHA: сегменты → проверка → активация → догон, с негативными случаями и сохранностью состояния | **В ПРОЦЕССЕ / NOT VERIFIED** | Живая синхронизация Floonet с нуля до `fully_synced` прошла на более ранней объединённой сборке (`16C24DB4…`). ## Не проверено

- **Mainnet:** запуска на кандидате нет. Не выводить готовность Mainnet из Floonet.
- **Потеря питания:** kill harness — не потеря питания.
- **Реальный отказ хранилища:** реальные write/commit-отказы RocksDB, post-commit, заполнение диска.
- **Публичный reorg:** только синтетические unit/integration сценарии.
- **Живые враждебные PIBD-пиры:** неверные сегменты, ложные баны на уровне P2P.
- **Кошелёк и UI:** см. ниже.
- **Linux/macOS runtime:** исходники совместимы, но в этом форке не проверены.
- **Длительная устойчивость:** многодневная работа и матрица перезапусков по стадиям.

## Кошелёк и UI

Код кошелька присутствует в дереве, потому что это полный форк Grin++, но
**кошелёк не входит в приёмку Node Beta**. Изменения кошелька покрыты только
unit-тестами автоматического набора; живых проверок кошелька, приёмки
отправки/получения и восстановления нет. Electron UI не входит в этот
репозиторий и **НЕ ГОТОВ**; его нельзя представлять как поставляемый или
поддерживаемый.

## Платформа и поставка

- **Проверено:** Windows 11 x64, Visual Studio 2022 MSVC 14.44, Release
  `/W4 /WX`, статический CRT. **Windows 10 x64 поддерживается исходниками, но
  здесь НЕ ПРОВЕРЕН.** Исполняемый файл линкует статический CRT (`/MT`) и на
  проверенной машине импортирует только системные DLL; запуск с сетевой папки —
  NOT VERIFIED.
- Готовые бинарники зависимостей не коммитятся в репозиторий. Инструкция по
  сборке описывает закреплённые ревизии и локальный sysroot.
- GitHub Actions workflow **подготовлен, но не выполнялся** в этом форке.
  Локальные скрипты не являются доказательством hosted CI.
