# Статус — кандидат Node Beta 1

Эта страница — авторитетное заявление о статусе снимка форка. Канонический
язык — английский; переводы: [STATUS.md](STATUS.md) (EN) и
[STATUS.de.md](STATUS.de.md) (DE).

Словарь статусов, используемый во всей документации:

| Метка | Значение |
|---|---|
| **PASS** | Наблюдалось на указанном коммите и бинарнике, в указанной среде и сценарии; доказательство зафиксировано. |
| **PARTIAL** | Реализовано и частично проверено; хотя бы один обязательный сценарий, среда или потребитель не проверены. |
| **FAIL** | Наблюдаемый отказ в определённом сценарии. Не используется, если тест просто пропущен. |
| **NOT VERIFIED** | Подходящих доказательств нет. Пропущенный тест, отсутствующая фикстура, таймаут или mock — не PASS. |
| **PLANNED** | Только проект/план; доказательств принятой реализации нет. |
| **EXPERIMENTAL** | Код есть, включение только opt-in; не рекомендуется для production или обычной работы. |

## Идентичность выпуска

| Пункт | Значение |
|---|---|
| Стадия | **Кандидат Node Beta 1**; метка Beta 1 этим документом не присваивается |
| Метка сборки/исходников | `node-beta.1-candidate` — аннотированный объект `fc5174ec…`, коммит `ccc4f356…` |
| Релизная метка | `node-beta.1` — укажет на финальный коммит документации; объект метки фиксируется при выпуске |
| База upstream | GrinPlusPlus `v1.2.9`, коммит `a0958a391c30cf630e3e08534fbc6fe9fb194326` (22.10.2024) |
| SHA-256 `GrinNode.exe` | `4039086CE339106DE37D7C6A98D54873171458699507DB18E938AFD938C80EFC` |
| SHA-256 `Tests.exe` | `A9594508FBDF5B48AA123A862CBB68B20882AD98BB8AA437A9E9A9C60D4FAC8C` — только для верификации, не входит в пользовательский пакет |
| Манифест исходников кандидата | `1528` файлов, SHA-256 `964B2DD8201018136EDFA3B87BFB98924F2A0FCAA508E5117DE2630380BA9627` |
| Проверенная платформа | Windows 11 x64, MSVC 14.44 (Visual Studio 2022), Release, `/W4 /WX`, статический CRT |

Результат принадлежит тому бинарнику и дереву, которые его произвели. Все
результаты ниже относятся к кандидату, если не указано иное. Более ранняя
объединённая сборка `GrinNode.exe` SHA-256
`16C24DB404702595EDB4CEDA7A057D2C187339FB92664473D211DFDB5F3FF3A2`
упоминается только там, где она является испытанным артефактом.

Счётчики сегментов PIBD зависят от прогона: кандидат стартовал с горизонта
`3 321 360` и показывает `4999/4999`; более ранняя объединённая сборка
стартовала с `3 320 640` и показывает `4998/4998`. Разница в один сегмент
следует из разной высоты горизонта и не является дефектом; счётчики не
переносятся между сборками.

не путали с «принятой Beta 1».

## Завершено после первого снимка

Живой прогон кандидата и чистая пересборка завершились после первого снимка
документации. Их результаты — в таблице «Реализовано и проверено» выше; ни один
результат не переносится на другой бинарник.

## Не проверено

- **Mainnet:** запуска на кандидате нет. Не выводить готовность Mainnet из Floonet.
- **Потеря питания:** kill harness — не потеря питания.
- **Реальный отказ хранилища:** реальные write/commit-отказы RocksDB, post-commit, заполнение диска.
- **Публичный reorg:** только синтетические unit/integration сценарии.
- **Живые враждебные PIBD-пиры:** неверные сегменты, ложные баны на уровне P2P.
- **Автоматические потоки rangeproof:** живой прогон кандидата использовал default 1 поток; `auto` на полном live-состоянии не проверялся.
- **FastInit:** в живом прогоне кандидата не использовался (событий `header_checkpoint_*` нет); остаётся экспериментальным.
- **Кошелёк и UI:** см. ниже.
- **Linux/macOS runtime:** исходники совместимы, но в этом форке не проверены.
- **Длительная устойчивость:** многодневная работа и матрица перезапусков по стадиям.

## Кошелёк и UI

Код кошелька присутствует в дереве, потому что это полный форк Grin++, но
**кошелёк не входит в приёмку Node Beta**. Изменения кошелька покрыты только
unit-тестами автоматического набора; живых проверок кошелька, приёмки
отправки/получения и восстановления нет. Electron UI не входит в этот
репозиторий и **НЕ ГОТОВ**; его нельзя представлять как поставляемый или
поддерживаемый.

## Платформа и поставка

- **Проверено:** Windows 11 x64, Visual Studio 2022 MSVC 14.44, Release
  `/W4 /WX`, статический CRT. **Windows 10 x64 поддерживается исходниками, но
  здесь НЕ ПРОВЕРЕН.** Исполняемый файл линкует статический CRT (`/MT`) и на
  проверенной машине импортирует только системные DLL; запуск с сетевой папки —
  NOT VERIFIED.
- Готовые бинарники зависимостей не коммитятся в репозиторий. Инструкция по
  сборке описывает закреплённые ревизии и локальный sysroot.
- GitHub Actions workflow **подготовлен, но не выполнялся** в этом форке.
  Локальные скрипты не являются доказательством hosted CI.
- **Лицензирование:** форк — MIT. Тридцать файлов, производных от Rust-ноды
  `grin` 5.5.2, несут comment-only заголовки атрибуции Apache-2.0; требование
  §4(c) на уровне файлов **выполнено** (см.
  [LICENSES/GRIN-DERIVED-FILES.md](../LICENSES/GRIN-DERIVED-FILES.md) и
  [NOTICE](../NOTICE)). `Logo.png` — **PARTIAL**: ассет upstream из
  первоначального коммита `7a4a6619` (17.12.2018, David Burkett), SHA-256
  `52658BE6…`, отдельной лицензии upstream нет; сохранён как MIT-ассет проекта
  upstream.
- **Поставка:** пользовательский релизный пакет содержит `GrinNode.exe` и
  документацию, но не `Tests.exe`. `Tests.exe` поставляется только в
  `verification/` для воспроизводимости; запускать его нужно с изолированными
  `HOMEDRIVE`/`HOMEPATH`/`TEMP`, свободным портом 3421 (только один экземпляр) и
  рабочим каталогом корня репозитория/сборки. Запуск против реального
  пользовательского профиля вызывал аварию `0xC0000409`. Не заявлять общую
  безопасность его выполнения.
