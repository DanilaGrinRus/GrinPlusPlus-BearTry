# Node Beta1 — предварительная RC1

**Статус:** кандидат для дальнейших испытаний, не принятая Beta1 и не stable release. Полный PIBD с нуля, Mainnet и перезапуски на этапах синхронизации на этом EXE ещё не подтверждены.

`GrinNode.exe` — Windows x64, SHA-256 `CD941F325B6E7595E9A777DDA90B486BCAFB0473322CBD95E3FCA5133344FD48`.

Для запуска ноды во **Floonet** без кошелька откройте `START_FLOONET_NODE.cmd`. Лаунчер создаёт профиль в `node-data` рядом с собой; нужны права на запись в папку. Логи создаются в `logs`. Обычный запуск EXE без параметров по умолчанию выбирает Mainnet и включает wallet.

- `source/` — исходники ноды, API и тестов, необходимые для самостоятельной сборки. Некоторые старые вспомогательные инструменты, привязанные к прежней машине, исключены; список в `source/OMITTED_LOCAL_TOOLS.md`.
- `dependencies/sysroot/` — предварительно собранные библиотеки Windows x64.
- `BUILD.ru.md` — инструкция сборки и тестов.
- `evidence/` — доказательства; старые прогоны и их пути имеют исторический характер и не используются как настройки запуска.
- `docs/` — снимки аудитов и API-матрицы; ссылки внутри исторических снимков могут не работать в другой папке.
- `SHA256SUMS.txt` — хэши файлов комплекта; пользовательский архив и создаваемые при работе данные в него не включены.

Скрытые harness-сценарии и живой fixture исключены; две внешние фикстуры в стандартном наборе отсутствовали и их проверки пропущены. Отображение сегментов PIBD проверено синтетическим тестом; живая загрузка не проверена. Лаунчер, HTTP health и штатное завершение проверены в перенесённой папке с пробелами без внешних пиров.

Owner RPC `compact_chain`, `validate_chain`, `reset_chain_head`, `invalidate_header` в этом кандидате не реализованы. Прерывание компактизации и перезапуск после фактического удаления ещё не подтверждены. API и логи на всех этапах синхронизации требуют живой проверки.

Комплект рассчитан на совместимую Windows x64, CMake/MSVC для сборки и доступную для записи папку. Два запуска и штатное завершение проверены на исходном компьютере в перенесённой директории с пробелами и кириллицей; на сторонней среде пользователь подтвердил запуск и загрузку заголовков; SHA той копии отдельно не измерен, сетевая папка не проверена. Остальные сторонние библиотеки независимо из исходников не пересобирались.

Статическая RocksDB для этой сборки пересобрана с UTF-8 путями Windows и переносимыми настройками; входящая в набор shared-версия не используется нодой и отдельно не проверялась.

На этом SHA чистая Floonet-нода без фиксированного списка пиров нашла 5 соединений и начала загрузку заголовков (512 из 3323361); полный PIBD и догон ещё не проверены. DNS-seeds приведены к Grin 5.5.2; исходящий TCP имеет пятисекундный предел и различает таймаут и код ошибки. Неверные magic bytes по-прежнему отвергаются и теперь диагностируются с указанием фактических и ожидаемых байтов. Наличие сетевых ошибок отдельных пиров не исключается. Набор NRD differential выполнен без внешнего Rust-oracle; это не подтверждение Rust-паритета.
